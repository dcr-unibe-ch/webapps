# DCR webapps

This site hosts a couple of small webapps developed at DCR. 

Depending on the complexity of the app, it may take up to a minute to initialize. Please be patient.

- [teachingsamplesize1](teachingsamplesize1/): A basic sample size calculation app for the DCR stats course
- [presize](presize/): An app for precision based sample size calculation (see [the package website](https://dcr-unibe-ch.github.io/presize) for more details)
